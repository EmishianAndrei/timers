# Таймеры дел

Несколько именных таймеров. Пауза не сбрасывает время, а в итогах видно, сколько ушло на каждое дело за день и за неделю.

- Режим «По одному»: запуск дела ставит остальные на паузу. «Параллельно»: таймеры идут независимо.
- Данные хранятся в браузере (localStorage) на конкретном устройстве. Сервера нет.
- Сайт работает без интернета, его можно установить как приложение: в Chrome или Edge кнопка «Установить» в адресной строке, в Safari «Поделиться → На экран „Домой“».

Статический сайт без сборки, публикуется через GitHub Pages из ветки `main`.
