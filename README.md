# Трекер

Личный трекер: **таймеры**, **трекер привычек**, **задачи**, **рецепты**, **финансы** и **цели**.
Сайт: https://emishianandrei.github.io/timers/

Данные хранятся в вашей Google-таблице (база) и в браузере (копия для работы без интернета).
Сайт не зависит от Claude или других сервисов, кроме GitHub Pages и вашего Google-аккаунта.

## Что умеет

- **Таймеры.** Названия задаёте вы, группы по желанию. Пауза не сбрасывает время. Режимы «секундомер» и «таймер» (45/60/90 мин,
  со звуком и уведомлением; после сигнала считает переработку), «по одному» и «параллельно».
  Таймер можно связать со строкой трекера: его время само попадёт туда в формате ч:мм.
  Есть итоги дня, шкала времени и график за 7 дней с легендой и подсказками.
- **Трекер.** Разделы и строки как в листе «Main»: сон (длительность считается из отбоя и подъёма), галочки,
  числа, выбор из списка, время суток, текст, время занятий (ч:мм) и приёмы пищи (№ блюда + время).
  Виды: день, месяц (таблица), графики (время по разделам, сон, привычки, числа) и настройка строк.
  «Скрыть» строку — это аналог «КОНЕЦ»: из новых дней пропадает, история остаётся.
- **Рецепты.** У каждого блюда свой номер, в трекере пишется номер, название подставляется само.
- **Задачи.** Как в Google Tasks: списки (с группами), подзадачи, даты, звёздочки, сортировки, перетаскивание,
  «Выполненные» и отмена действия.
- **Финансы.** Операции по категориям, доходы и расходы за месяц, «мои расходы» и долги с историей.
- **Цели.** Цели на месяц с автопрогрессом (дни с галочкой, пары или сумма по категориям), еженедельные дела,
  триггеры, хотелки и подарки, долгосрочные навыки.

## Установка базы (один раз)

1. Откройте таблицу-базу → **Расширения → Apps Script**.
2. Удалите всё в `Code.gs` и вставьте код из [`apps-script/Code.gs`](apps-script/Code.gs).
3. В строке `const SECRET = '...'` впишите свой ключ (любая длинная строка) и сохраните (Ctrl+S).
4. Выберите функцию **setup** → **Выполнить** → разрешите доступ.
   Будут созданы недостающие листы и ежедневная копия таблицы в папку «Трекер — резервные копии» на Диске.
5. **Начать развёртывание → Новое развёртывание → Веб-приложение**. Запуск от имени: **Я**, доступ: **Все**.
6. Скопируйте URL и вставьте его вместе с ключом на сайте во вкладке **Настройки**.

Ключ не хранится в репозитории: он есть только в вашей таблице и в настройках сайта на ваших устройствах.

После правки скрипта: **Начать развёртывание → Управление развёртываниями → ✎ → Версия: новая**. URL не меняется.

## Копии данных

- **Google Диск:** ежедневная копия таблицы, хранятся последние 30.
- **Файл:** «Настройки → Скачать копию (.json)». Восстанавливается там же.
- **Код сайта на ноутбуке:** `git clone https://github.com/EmishianAndrei/timers.git`.
  Сайт можно открыть локально: `cd timers && python3 -m http.server 8000`, потом http://localhost:8000.

## Устройство

Статический сайт без сборки: `index.html` (вёрстка и стили), `js/*.js` (логика по разделам), `sw.js` (работа без интернета).
Листы базы и их столбцы описаны в `SCHEMA`: одинаково в `js/core.js` и `apps-script/Code.gs`.
